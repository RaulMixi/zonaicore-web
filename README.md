# Zonai Web

Frontend de Zonai, creado con React, TypeScript y Vite.

## Requisitos

- Node.js 20.19+ (o 22.12+)
- npm

## Desarrollo

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
npm run preview
```

El sitio se prepara para GitHub Pages en `https://raulmixi.github.io/zonaicore-web/`.

> La vista inicial es solo la estructura visual. El backend actual permite guardar snapshots de recordatorios, pero todavía necesita endpoints de lectura antes de que el frontal pueda mostrar datos reales.
